# 依赖安全复核

[English](dependency-security.md)

本地和 CI 使用 `node tools/dependency-audit.mjs /tmp/npm-audit.json`，完整执行 npm 审计，并保留原始 JSON。未复核漏洞、网络错误、无效响应和退出状态不一致都会阻止发布。

2026-11-18 对 [GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf) 做了适用性复核，维护复核日期为 **2026-11-25 00:00 UTC**，并绑定当前锁文件及应用、构建和配置范围的 SHA-256。上游最新 picomatch 4.0.7 仍受影响，暂无正式修复版本。本次 14 项高危告警是同一公告沿依赖链传播的结果。

利用条件是攻击者能够提供重复 extglob 表达式。本站为静态构建，匹配表达式来自可信仓库配置；应用不接收用户 glob，日报 Markdown/JSON 不作为构建配置执行，线上没有 Node 服务。基于此已核查的使用范围接受该项风险，**并未修复 picomatch 本身**。

检查器只接受该公告、包名、影响范围和严重性，以及完全追溯到该公告的依赖链。新漏洞、混合依赖链、缺失引用、循环引用、依赖及应用或构建配置变更仍阻止发布。审计原文上传为 CI artifact；例外在控制台明确显示。

`tools/security-applicability.json` 记录具体公告、锁文件及完整应用/构建范围的摘要；检查器不会自动重写它。范围包含 src、scripts、tools、.github、config、public 以及根目录的代码和配置文件，新增或删除文件也使复核失效。文档及 artifacts 报告数据不属于可执行范围，普通内容更新无需重新复核。

维护日期届满后，范围未变化的适用性判断继续有效，同时明确警告维护逾期。独立的每日安全工作流执行完整 npm 和严格 Python 审计，保存原文，通过现有 Issue 机制追踪逾期、未知或阻塞结果；只有完整、当前、成功的证据才会关闭 Issue。未知漏洞、网络/进程错误仍会失败。不得只为通过检查而重写摘要；应检查上游修复并重新核查可信 glob 假设，再显式更新复核记录。引入外部 glob 或不可信构建配置时立即失效。

浏览器缓存绑定精确 Playwright 版本、操作系统与架构，不使用宽泛回退。安装有明确时限，缓存命中后仍校验安装并准备系统依赖；源码和内容两套完整浏览器门禁均保留。完整范围与复核依据见英文文档。
