# 分段下载报告图片

报告页面保留整张 PNG 下载，也提供分段下载菜单。展开报告旁边的菜单，选择需要的章节即可保存。美股报告、亚洲晚报和周报都支持这一入口。

菜单根据报告已有内容分组。市场概览、行业排名和资金流向可以单独下载，历史走势和研究说明也各有入口。报告缺少某类内容时，对应按钮会隐藏。其余补充数据保留在补充组中。

每张分段图片都带有报告日期和章节标题，并保留来源与限制说明。它使用网页所用的同一份 `ReportDocument`，原始数值和观测日期保持不变。需要展开查看的来源材料继续保留在网页和原始文件中，与整图下载的范围一致。

## 文件名

分段文件使用 `<date>-<kind>-<section>-report.png`。例如，亚洲晚报的资金流向图片可保存为 `2026-10-29-asia-daily-money-flow-report.png`。

整张报告的文件名保持原样。下载器只接受已有报告类型，以及长度受限的小写章节标识。同一页面有多份报告时，按钮会从各自的菜单中查找图片。

## 图片限制

分段图片沿用现有 SVG 渲染、主题和 PNG 下载器。SVG 的逻辑高度上限为 8000 像素，PNG 继续遵守单边 8192 像素及总面积 1200 万像素的限制。

整图超过高度上限时，整图按钮会隐藏，菜单会说明可以分段下载。每个分段仍需通过相同的高度检查。分段超限会继续抛出渲染错误，由发布检查阻断当前候选。其他渲染错误继续阻止导出。

发布检查可读取 `ReportImageBudgetError`。它通过 `code=report_image_height_exceeded` 和实测 `height` 标识高度超限，便于区分整图分段降级与无效的分段图片。
