# 亚洲市场概览的来源时间类型

页面从带日期的机器标记读取时间含义。显示文案可以单独修改，历史报告仍按独立的兼容常量读取。

[英文完整说明](asia-overview-time-metadata.md)记录生产格式和消费规则。

生产者在 `### 亚洲市场概览` 节内写入一个标记。

```markdown
<!-- market_intel.asia_overview.v1 {"date":"2026-10-16","source_time_kind":"exchange_session_close"} -->
```

版本前缀限定该标记只描述概览中的来源时间。JSON 只含按顺序排列的 `date` 和 `source_time_kind`，采用紧凑编码。日期必须与报告日期一致。`exchange_session_close` 表示交易所日历中的收盘时间，行情发布时间仍未由这个字段核实。抓取时间保留在报告生产方的事实文件中。

页面只接受一个不超过 2048 个 UTF-8 字节的标记。版本、类型或日期不符合约定时，页面保留已通过原有校验的市场行，隐藏时间类型判断并显示待核实提示。重复标记、重复 JSON 字段和格式错误也按这个规则处理。

没有新标记时，历史原句仍能按兼容规则读取。坏标记不能借用历史原句通过校验，其他章节中的标记也不会生效。`sourceTimeSemantics` 只控制显示文案，旧原句及其英文翻译保留独立映射。

测试覆盖改写文案、历史报告和错误标记，中英文数值与观测日期保持一致。生产方和消费方分别提交 PR，先集成生产方，再按既有发布流程接入。任务分支通过测试不代表已经部署。
